MONKA'S DREAMY PINK & LAVENDER BIRTHDAY WEBSITE

Files:
- index.html: complete website, all CSS and JavaScript included.

HOW TO TEST LOCALLY:
1. Keep this folder separate from your old website folder.
2. Double-click index.html to open it in your browser.
3. The music permission popup appears first. Browsers may still block audio; clicking Yes is a user gesture and starts a playback attempt.
4. Try all questions and the photo preview section.

PRIVACY:
- Answers exist only in page memory and are not uploaded.
- Photos are previewed using local browser object URLs and are not uploaded to a server.
- Reloading/closing the page clears answers and photo previews.
- Music is loaded from a third-party audio URL, so internet access is needed for that track.

PUBLISHING LATER:
Once tested, upload this index.html to a NEW GitHub repository or a separate branch/folder. Do not overwrite the existing live site until you are sure.
